# 技術決策紀錄

語言、框架、函式庫、程式結構由 Claude 決定。每做一個這樣的決定，就在這個資料夾留一份短 ADR。產品方向（要做什麼）不寫在這裡；那種問題用 `needs-human` 問你。

檔名是 `NNNN-title.md`：四位數字、連字號、英文小寫。從 `0001` 往後加。例如 [0001-placeholder-ci.md](0001-placeholder-ci.md)。

每份用這四個標題：

## Context

為什麼現在要決定。

## Decision

決定是什麼。

## Alternatives

想過哪些做法、為什麼不用。

## Consequences

這個決定之後會怎樣，以及什麼時候要再看一次。
