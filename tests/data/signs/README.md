# 招牌辨識測試照片（#22）

這些是 Wikimedia Commons 上授權允許重新散布的真實照片，用來測量本機招牌辨識的命中率（`python -m travelphotos.places.benchmark`）。
每張都已縮小（最長邊 800 px），盡量選沒有清楚人臉的照片；雷門那張已裁掉行人。授權為 CC BY-SA 的照片，修改後的版本仍以同一授權提供。
`expected` 是照片應對到的測試行程站名（`null` = 不應對到任何站）；`set` 為 `tuning`（設計比對規則時用過）或 `held-out`（規則定案後才加入）。
